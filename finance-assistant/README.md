# Теңге · Персональный финансовый ассистент

MVP для хакатона: React + TypeScript + TailwindCSS + Recharts, FastAPI, SQLAlchemy + SQLite и Claude `claude-sonnet-4-6`. Русский интерфейс, адаптивный дашборд, работа без API-ключа.

## Запуск одной командой

Установите Docker Desktop с Compose. Из этой папки:

```sh
docker compose up --build
```

- Приложение: http://localhost:5173
- API и интерактивная документация: http://localhost:8000/docs
- SQLite сохраняется в именованном Docker volume `finance_data`.

Нажмите **«Загрузить CSV» → «Попробовать 80 демо-транзакций»**. Демо создаётся за текущий и предыдущий календарные месяцы, без будущих дат. Готовый пример также лежит в `demo-transactions.csv` и доступен по `/api/demo.csv`.

Для настоящего ИИ скопируйте `.env.example` в `.env`, укажите `ANTHROPIC_API_KEY`, затем пересоздайте backend:

```sh
docker compose up -d --force-recreate backend
```

Нажмите **«Повторить категоризацию через Claude»** и **«Обновить анализ»**. Без ключа категории определяются простыми правилами, а карточки генерируются локальными шаблонами. Это явно обозначено в интерфейсе; чат без ключа возвращает понятное сообщение об ошибке. Демо-кнопка намеренно не расходует токены.

## Запуск без Docker

Python 3.12+, Node.js 22+ с npm. В первом терминале:

```sh
cd backend
python -m venv .venv
# Windows PowerShell:
.venv\Scripts\Activate.ps1
# macOS/Linux: source .venv/bin/activate
pip install -r requirements.txt
uvicorn app.main:app --reload --port 8000
```

Для ИИ задайте переменную окружения `ANTHROPIC_API_KEY` либо создайте `backend/.env` с ключом. Для локального запуска база по умолчанию — `backend/finance.db`.

Во втором терминале:

```sh
cd frontend
npm install
npm run dev
```

Vite перенаправляет `/api` на порт 8000; Docker использует nginx. Ключ доступен только backend.

## CSV

```csv
дата,описание,сумма,тип
2026-09-01,Зарплата,480000,доход
2026-09-02,Magnum,6400,расход
2026-09-03,Кофейня,1500,расход
```

- Заголовки: `дата, описание, сумма` либо `date, description, amount`; `тип` / `type` необязателен.
- Явный тип `доход/расход` (`income/expense`) имеет приоритет над знаком. Без типа отрицательная сумма — расход, положительная — доход.
- Даты: `YYYY-MM-DD`, `DD.MM.YYYY`, `DD/MM/YYYY`, не в будущем.
- Разделитель `,` или `;`; десятичная запятая поддерживается в кавычках либо с разделителем `;`.
- UTF-8 (включая BOM), Windows-1251. До 2 МБ и 1 000 строк; до двух десятичных знаков; нулевые суммы запрещены.
- Файл валидируется целиком до записи. Ошибка содержит номер строки. При повторном импорте уже существующие сочетания дата + описание + сумма + тип пропускаются. Одинаковые строки внутри первого файла сохраняются. Импорт пересекающихся выписок с несколькими реально одинаковыми операциями требует внимания: без банковского ID надёжно различить их невозможно.
- Все суммы должны быть в одной валюте. Переключатель KZT/RUB меняет только обозначение, не конвертирует деньги. Демо рассчитано на KZT.

## Что реализовано

- CSV-импорт, атомарное сохранение, защита от повторного импорта, SQLite-модели User / Transaction / Category.
- Claude Structured Outputs через `output_config.format`, проверка JSON Pydantic, пакеты по 25 операций, проверка идентификаторов, таймауты, резервная локальная категоризация и повтор через ИИ.
- Доходы, расходы, баланс месяца; круговая диаграмма; дневная динамика; топ-5; сравнение с предыдущим месяцем.
- Ровно 3 наблюдения и 2 совета; кэш по дате, месяцу и данным. Обновление по запросу, автоматический запрос при открытии месяца. Фонового планировщика нет.
- Линейный прогноз: расходы / число прошедших календарных дней × число дней месяца. Остаток = уже полученные доходы − прогноз расходов. Начальный баланс 0, будущие доходы не прогнозируются. Исторические месяцы используют все дни месяца. Неполная выписка искажает прогноз.
- Чат по агрегатам выбранного месяца и топ-5 операциям, без истории диалога.
- Нет авторизации, банковских интеграций и конвертации валют. Приложение предназначено для локального однопользовательского демо; Compose публикует порты только на loopback.

Claude получает описания для категоризации, агрегаты и топ-5 для анализа/чата. SQLite хранится локально; использование Claude означает передачу этих данных в Anthropic. Описания транзакций отделены от системных инструкций. Исходный CSV не сохраняется.

## API

| Метод | Путь | Назначение |
|---|---|---|
| POST | `/api/upload` | multipart `file`, загрузка CSV |
| POST | `/api/demo` | Добавить демо-набор |
| GET | `/api/demo.csv` | Скачать актуальный пример |
| POST | `/api/categorize` | Повторить локальные/неразмеченные расходы через ИИ |
| GET | `/api/months` | Месяцы с данными |
| GET | `/api/dashboard?month=YYYY-MM` | Аналитика |
| POST | `/api/insights?month=YYYY-MM&refresh=false` | Карточки анализа |
| POST | `/api/chat` | JSON `{ "month": "2026-09", "message": "…" }` |
| GET | `/api/health` | Проверка доступности |

## Проверка

```sh
cd backend
python -m pytest tests -q
cd ../frontend
npm run build
```

Тесты используют отдельную временную БД и подменяют ИИ. Проверяют валидацию CSV, точность денежных сумм, атомарность, повторный импорт, аналитику, прогноз, кэш, fallback, пакетирование и сопоставление ID.

Документация протокола Claude: https://platform.claude.com/docs/en/build-with-claude/structured-outputs
